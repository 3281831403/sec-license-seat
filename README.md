授权按席位计费，一个账号在多台设备同时登录，席位却没被回收，超卖了一批：席位按账号唯一占用，同一账号在任意多台设备上登录都只对应一个席位；占用必须有租约并支持续期；租约过期后必须先回收再分配；席位释放后立即可被其他账号占用；并发申请不得超过总席位；批量申请时各租户的余量互相独立。任何时刻已用席位与剩余席位之和等于总席位；同一账号重复申请必须返回原有席位。
